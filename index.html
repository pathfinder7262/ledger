🔐 Hash Chain Integrity Verification

Each entry is chained using SHA-256. If anyone tampers with any entry in the database, the chain breaks.

ℹ️ How It Works

  • Every entry gets a SHA-256 hash from its content + previous hash
  • Entries are chained — modifying any past entry breaks all hashes after it
  • Data stored in Firebase cloud — not in your browser
  • Auto-sync every 5 seconds — both users see updates live
  • PIN-protected — nobody can impersonate you
  • No delete function exists — entries are permanent
